    Asumsi perilaku firmware
    • FORWARD AUTO: ikuti garis dengan PID; kecepatan = rata-rata LEFT/RIGHT (PWM 0–255). MANUAL / BACKWARD: PWM LEFT & RIGHT dipakai apa adanya.
    • DELAY: cm untuk FORWARD/BACKWARD, ms untuk TURN & PAUSE.
    • MOTION SENSOR: langkah menunggu pola sensor terpenuhi (OR = salah satu; XR/EQ = tiap kelompok ada yang aktif; XN = persis sama), lalu menjalankan DELAY. Pada TURN: DELAY dulu, baru menunggu sensor.
    • JUMP TO PLAN: LEFT = plan (1–12), RIGHT = index tujuan. Jika sensor dipilih, lompat hanya bila pola cocok.
    • FOLLOW: CENTER = pusat semua sensor aktif; LEFT/RIGHT = ikuti kelompok sensor paling kiri/kanan (cabang).
    • SPEED A / TIMER A: kecepatan awal selama TIMER A cm. SPEED B / TIMER B: pelan di TIMER B cm terakhir (hanya TYPE SB = LOCK). FREE: roda meluncur saat berhenti.
    • CAL tidak berpengaruh (sensor ideal). FAN & GRIPPER hanya ditampilkan di robot.
